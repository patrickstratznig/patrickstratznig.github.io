2. What does the app do?

Postleitzahlen Österreich provides Austrian postal code and location lookup functionality. Users can search for postal codes, places, and related location information. The core lookup functionality works offline using postal code and location reference data bundled with the app.

4. Manual searches

When you manually search for postal codes, places, or related location information, your search input is processed locally on your device. Manual search queries are not sent to our own servers.

The app does not require you to create an account and does not associate your manual searches with your name, email address, or any user profile operated by us.

5. Location permission and location data

The app may optionally request access to your device location if you actively use a location-based feature, for example by tapping a location button. Location access is not required for manual postal code or place search.

If you grant location permission, Android may provide approximate or precise location depending on the permission option you choose. The app uses this location to determine nearby postal code or location information.

The app itself does not send your location to our own servers for postal-code lookup. However, advertising SDKs may process approximate location, device-related information, advertising identifiers, or similar data as described in the advertising section of this Privacy Policy.

The app does not use your location to create a movement profile and does not store your location history on our own servers.

The app does not request background location access. Location is only used for the requested location-based lookup functionality while you are using the app.

You can withdraw location permission at any time in your Android system settings.

6. No background location

The app is not designed to access your location in the background. It does not request Android's background location permission and does not need background location for its core functionality.

7. Offline data

The app includes Austrian postal code and location reference data bundled with the app. This data is used locally on your device. The core lookup functionality does not require an internet connection.

Updates to the bundled postal code and location reference data may be provided through normal app updates.
